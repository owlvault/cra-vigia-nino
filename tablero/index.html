Protocolo en ArcGIS Pro

El analista SIG procesa las capas espaciales en su software de escritorio:

  • Importar: Usa JSON To Features o XY Table To Point.
  • Unir polígonos: Add Join con MGN_MPIO_POLITICO.shp del DANE por DIVIPOLA.
  • Enriquecer: Cruce espacial con cuencas IDEAM, distancias a embalses y focos de calor.
  • Exportar: Herramienta Features To JSON (marcando casilla GeoJSON).
